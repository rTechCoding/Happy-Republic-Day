# Happy-Republic-Day
🇮🇳 Happy Republic Day – Interactive Celebration Page  An interactive single-page Republic Day celebration website built using pure HTML, CSS, and JavaScript. The page visually represents India’s tricolor spirit with animated fighter jets, a rotating Ashoka Chakra, and automatic party popper confetti celebrations
✨ Features

🇮🇳 Tricolor-themed UI inspired by the Indian National Flag

☸️ Animated Ashoka Chakra (CSS-only rotation)

✈️ Auto-flying fighter jets symbolizing Indian Air Force fly-past

🎉 Party popper / confetti animation

Auto-triggers every 3 seconds

Manual trigger via “Celebrate India” button

📱 Fully responsive (desktop & mobile friendly)

⚡ No external JavaScript libraries

📄 Single HTML file – easy to deploy & share

🛠 Tech Stack

HTML5

CSS3 (Animations, Gradients, Keyframes)

JavaScript (Vanilla)

Font Awesome (for fighter jet icons)

🚀 How It Works

Fighter jets animate continuously across the screen using CSS keyframes

Confetti bursts are generated dynamically using JavaScript DOM elements

A timed setInterval() triggers celebration effects automatically

All effects run smoothly without page reloads
